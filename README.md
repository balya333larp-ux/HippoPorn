# Hippo Strike — онлайн на Cloudflare, без команд на компьютере

Это отдельная готовая Cloudflare-сборка Hippo Strike 4.9.1. Сайт и сервер комнат размещаются вместе в Cloudflare Worker. Durable Object с SQLite хранит профили/друзей и координирует общие комнаты и WebSocket. Не нужно держать свой ПК включённым, открывать порт 3000, покупать VPS или домен.

## Опубликовать через браузер

1. Распакуй архив. Внутри должны быть `package.json`, `wrangler.jsonc`, папки `public` и `worker`.
2. На https://github.com/new создай репозиторий **hippo-strike-online**. Можно Public или Private, если твой Cloudflare Git-доступ позволяет выбрать его.
3. В репозитории выбери **Add file → Upload files** (в новом пустом репозитории — uploading an existing file). Перетащи СОДЕРЖИМОЕ распакованной папки, включая папки public и worker. Не загружай ZIP одним файлом и не добавляй лишний внешний каталог. Нажми **Commit changes**.
4. Проверь: package.json и wrangler.jsonc видны прямо в корне репозитория, а index.html находится в public.
5. Открой https://dash.cloudflare.com/ → **Workers & Pages → Create application → Import a repository / GitHub**. Это создание **Worker**, НЕ Pages Upload assets.
6. Подключи GitHub и выбери созданный репозиторий.
7. Настройки:
   - Worker name: **hippo-strike-online** — имя должно совпадать с name в wrangler.jsonc.
   - Production branch: **main**.
   - Root directory: корень репозитория, **/** (не public и не worker).
   - Build command: **пусто** — клиент уже собран.
   - Deploy command: оставь стандартный **npx wrangler deploy**. Он выполняется у Cloudflare, а не на твоём ПК. Ничего устанавливать и вводить в терминале не нужно.
8. Нажми **Save and Deploy / Deploy**. Конфигурация сама создаст binding HIPPO_HUB и SQLite Durable Object HippoHub. Не создавай вручную другой тип хранилища и не включай платный тариф.
9. После успешного деплоя открой выданную ссылку **https://hippo-strike-online.<твой-поддомен>.workers.dev**.
10. В игре открой **Играть → Онлайн**. Должен появиться статус подключения. Создай публичную комнату, затем отправь другу ту же ссылку и код комнаты. Друг открывает её в своём браузере и входит в ту же комнату. Настройки адреса сервера вручную не нужны.

Для диагностики открой `/health` (ok: true) и `/info` (cloudflare: true, build: 490) на своём домене Worker.

Локальный Wrangler НЕ нужен. В проекте есть конфигурация Wrangler, которую читает встроенная сборка Cloudflare. Полностью исключить внутренний инструмент сборки из этого Git-деплоя нельзя, но пользователь работает только в браузере.

## Бесплатность и ограничения

SQLite Durable Objects доступны в Workers Free. Для этой конфигурации не нужно подключать платный Workers, вводить банковскую карту или покупать домен. Если интерфейс предлагает обязательную оплату — не оплачивай: проверь, что выбран Worker Free и SQLite, а не платная услуга. На аккаунте могут действовать дополнительные проверки Cloudflare.

Бесплатный тариф имеет квоты на Worker/Durable Object запросы, вычисления и SQLite. Это не безлимитный игровой хостинг: при превышении бесплатных лимитов операции могут перестать работать до сброса квоты. Не обещается бесплатное обслуживание большого публичного сервера. Сначала проверь игру вдвоём/небольшой группой.

Состояние комнат обслуживает один общий Durable Object — это намеренная простая архитектура для небольшого сообщества, а не глобальная многорегиональная система матчмейкинга. Игровые сообщения ограничены по размеру/частоте; максимум комнаты — 12 игроков, программный потолок соединений на хабе — 200, но это не обещание такой вместимости на бесплатном тарифе.

Сервер по-прежнему ретранслирует игровую физику и попадания клиентов. Это НЕ сервер-авторитетный античит. Список друзей хранится постоянно в SQLite. Ключ профиля живёт в браузере на домене сайта; очистка данных браузера или смена домена даст новый профиль. Профили локального Node-сервера автоматически не переносятся.

Сон Durable Object восстанавливает подключения и комнаты из attachment/SQLite. После развёртывания новой версии или сетевого разрыва клиент пытается переподключиться, но автоматический возврат в прежний матч не гарантируется: при необходимости войди в комнату снова.

## Что сохранено

9 карт, ИИ для офлайна, гранаты, No Flash/No Spread, бинды, 72 готовые раскидки и три конфига 4.9.1. Для онлайн-матчей используются другие подключённые игроки, а не общие серверные боты. Модерация и отрисовка маршрутов прострела не возвращены. Сетевой протокол — 490.

## Обновить игру

Загрузи изменённые файлы в тот же GitHub-репозиторий и сделай Commit changes — подключённая Git-интеграция запустит новый деплой. Не удаляй Durable Object namespace и не меняй migration v1 без необходимости: это может затронуть сохранённые профили. После обновления друзья должны перезагрузить страницу.

## Если сборка не проходит

- Worker name mismatch — поставь имя hippo-strike-online в панели, как в wrangler.jsonc.
- Не найден конфиг/файлы — проверь корень репозитория и Root directory.
- HIPPO_HUB missing — опубликован не весь проект или использован Pages/ручная вставка одного JS. Импортируй весь репозиторий как Worker.
- Игра открывается, но /info даёт 404 — опубликованы только статические файлы. Для онлайна нужен Worker с Durable Object.
- Требуется карта — не включай платные дополнения; проверь, что используется Free и new_sqlite_classes из предоставленного конфига.
